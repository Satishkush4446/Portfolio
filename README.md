## 🚀 Overview

A high-performance personal portfolio built with React 19 and Vite 8, featuring:
- **GSAP & ScrollTrigger:** Hardware-accelerated entrance animations and numerical counter scrolls.
- **Lenis Smooth Scroll:** Synchronized inertial scrolling with `prefers-reduced-motion` compliance.
- **Bento Grid Architecture:** Responsive showcase of 100+ production sites, 50+ migrations, and awards.
- **Awards Exhibition:** Dual "Star of the Month" honors from Adaan Digital Solutions with full-screen SVG certificate lightboxes.
- **Case Study Modal:** In-depth technical breakdowns with problem/solution analysis and quantitative business metrics.

---

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite 8
- **Styling:** Custom Modular CSS Architecture (Design Tokens, Responsive Bento Grid, Glassmorphism)
- **Motion:** GSAP 3 + ScrollTrigger & Lenis Smooth Scroll
- **Icons:** Lucide React
- **Linter & Tests:** Oxlint + Vitest & React Testing Library

## 📦 Getting Started

### Prerequisites
- Node.js (v18.0 or higher recommended)
- npm

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/Satishkush4446/Portfolio.git

# Navigate to project folder
cd Portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Scripts

```bash
npm run dev      # Start Vite local development server (http://localhost:5173)
npm run build    # Compile production bundle to /dist
npm run preview  # Locally preview production build
npm run lint     # Run Oxlint static analysis
npm test         # Run Vitest component and unit test suite
```
